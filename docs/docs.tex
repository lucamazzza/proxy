\chapter{Abstract}

Le policy di sicurezza di rete moderne spesso isolano sia client che server rendendo
impraticabili le connessioni dirette senza l'utilizzo di complesse configurazioni.
Questo progetto espone il design e lo sviluppo di un'\textbf{architettura client-server}, pensata per superare le limitazioni
imposte da firewall e NAT nelle reti private.
Il meccanismo centrale \textbf{sostituisce} le tradizionali \textbf{connessioni socket} con un approccio basato su 
\textbf{REST + WebSocket}, utilizzando Appwrite\footnote{\url{https://appwrite.io}} come Proxy.
Il sistema crea un \textbf{canale} di comunicazione \textbf{sicuro} su cui client e server interagiscono asincronamente 
tramite eventi di creazione di documenti nel database di Appwrite.

Viene quindi sviluppata una \textbf{libreria modulare} in C++ (con QT) per astrarre l'API di Appwrite, implementando 
funzionalità come la gestione delle \textbf{sessioni}, l'identificazione dei canali basata su \textbf{UUID} e la 
serializzazione dei payload in \textbf{JSON}. L'implementazione di tale libreria viene validata attraverso lo sviluppo 
di una semplice applicazione \textbf{Proof of Concept} (PoC), un \textbf{frontend}, realizzato con Qt/QML e compilato 
con WebAssembly per l'esecuzione in browser, e un servizio \textbf{backend} nativo in C++.

\vspace{0.5cm}
\noindent\rule{\textwidth}{0.5pt}
\vspace{0.5cm}

\noindent Modern security policies often restrict direct client-server communication, especially in private networks.
This project details the design and development of a \textbf{client-server architecture}, designed to overcome the
limitations of firewalls and NAT in private networks.
The core mechanism \textbf{replaces} the traditional client-server \textbf{socket connections} with a
\textbf{REST + WebSocket} based approach, using Appwrite as a Proxy.
The system creates a \textbf{secure} communication \textbf{channel} on which clients and servers interact 
asynchronously via document creation events in the Appwrite-hosted database.

A modular C++ (with QT) \textbf{library} is developed to abstract the Appwrite API, implementing features such as 
\textbf{session} management, \textbf{UUID}-based channel identification and \textbf{JSON} payload serialization. 
The implementation of said library is validated through the development of a simple \textbf{Proof of Concept} (PoC) 
application, a \textbf{frontend}, built with Qt/QML and compiled with WebAssembly for browser-based execution, and a 
native C++ \textbf{backend} service.
