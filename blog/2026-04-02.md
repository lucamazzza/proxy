Vista l'avvicinarsi imminente della fine della fase di sviluppo di `appcomm` è ora necessario iniziare il test della
libreria come unità, quindi il proof of concept.
Prima di fare ciò è però necessario testare con un'istanza reale, il modulo `AppwriteSDK`, ma per fare questo è necessario
documentarsi sulle necessità di code integration.

Di seguito un riassunto:

* Configurare i "Secrets" `APPWRITE_ENDPOINT`, `APPWRITE_PROJECT_ID` e `APPWRITE_API_KEY`
* Modificare i test, per l'utilizzo delle variabili d'ambiente sovraccitate

```cpp
void tst_appwritesdk::initTestCase()
{
    m_config.endpoint = qEnvironmentVariable("APPWRITE_ENDPOINT", "http://localhost/v1");
    m_config.projectId = qEnvironmentVariable("APPWRITE_PROJECT_ID", "test-project");
    m_config.apiKey = qEnvironmentVariable("APPWRITE_API_KEY", "test-api-key");

    m_config.dbId = "ci_test_db_" + QString::number(QDateTime::currentMSecsSinceEpoch());
    m_config.collectionId = "ci_test_coll";

    m_network = new QNetworkAccessManager(this);
    m_client = new appwritesdk::Client(m_network, this);
    m_server = new appwritesdk::Server(m_network, this);
}
```

* Aggiornare il workflow similarmente a come segue:

```yml
    # ... passi precendenti
    - name: Run Tests
      env:
        APPWRITE_ENDPOINT: ${{ secrets.APPWRITE_ENDPOINT }}
        APPWRITE_PROJECT_ID: ${{ secrets.APPWRITE_PROJECT_ID }}
        APPWRITE_API_KEY: ${{ secrets.APPWRITE_API_KEY }}
      run: |
        ctest --test-dir build/test --output-on-failure
```

* Strategia di test: `initTestCase` controlla la disponibilità del server, il primo test dovrebbe
essere `testCreateDB`, dimodoché gli altri test abbiano a disposizione un database, `cleanupTestCase`
pulisce l'istanza.
* Usare il pattern *Create-and-Verify* dopo laa creazione di ogni risorsa per verificarne l'esistenza
sul server.

```cpp
void tst_appwritesdk::testCreateCollection()
{
    QSignalSpy successSpy(m_server, &appwritesdk::Server::requestSuccess);

    // Creazione
    m_server->createCollection(m_config, "VerifiedCollection");
    QVERIFY(successSpy.wait(10000)); // Attesa asincrona

    // Recupero esplicito
    QSignalSpy verifySpy(m_client, &appwritesdk::Client::listDocuments); 
    m_client->listDocuments(m_config);
    QVERIFY(verifySpy.wait(10000));

    // Il server deve rispondere con un oggetto valido, non 404
    QJsonObject response = verifySpy.first().at(0).toJsonObject();
    QVERIFY(!response.isEmpty());
}
```
